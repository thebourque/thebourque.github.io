GUMBO — Wave / Contrac-adjusted remaining

Project-grain (CA/CDA/DA/AG) miles, passings, and BEAD, grouped by wave, filterable by parish, wave, and any one-or-multiple projects. Plan remain = households_to_be_built / model_miles_to_build (core_rules_plan_field_remainder). Contrac-adjusted remain overlays live field status (contrack_roq_outcome_v1, joined on ocius_project_id) — mainline (miles) and non-mainline (passings/BEAD) are not treated the same way: Contrac Complete → miles = plan minus Contrac's own built miles, passings/BEAD = 0 (display-only — does not rewrite the plan value); Contrac In Construction → miles get the same field-built adjustment, but passings/BEAD stay frozen at the plan value until Contrac reports the job Complete (perc_complete is a mileage-build percentage, not a passings/CPE/drop signal — core_rules_plan_field_remainder); no Contrac ROQ job (parent/off-grid row) → plan value unchanged for both. Same method as the St. Landry Parish report sent to Josh Richardson 2026-08-18. All filtering and CSV export run locally in your browser — no server, nothing sent anywhere.
